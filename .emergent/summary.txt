**original_problem_statement:**
The user wants to build a job board app for medical professionals that functions like Tinder for job matching.

**PRODUCT REQUIREMENTS:**
-   **User Roles:** Job Seekers and Job Posters.
-   **Profiles:**
    -   **Seekers:** Universal application with contact info, work history, certifications, licenses, pay expectations, desired benefits, and medical records (TB tests, vaccinations, physicals).
    -   **Posters:** Job location, assignment duration, benefits, job description, pay range, time off policies, and requirements.
-   **Matching:**
    -   Swipe-right for interested, swipe-left for uninterested.
    -   Mutual match notifications.
    -   Compatibility scores based on profile data.
    -   Swipe-up on a card to view more profile details.
-   **References:**
    -   Job seekers can request references, which are only visible to job posters after a match.
    -   Job posters can request facility reviews from current employees, which are not visible to the poster.
-   **Documents:**
    -   Users can upload documents (.pdf, .jpg, .jpeg).
    -   The system should send renewal notices 30 days before a document's expiration date.
    -   Weekly reminders for document expirations.
-   **Notifications:**
    -   User preference for email or SMS notifications (or both).
    -   Control over notification frequency.
    -   The system should be set up to integrate SendGrid (email) and Twilio (SMS), ready for API keys to be added.
-   **License Verification:**
    -   Implement a multi-tiered license verification system:
        1.  Admin verification (manual).
        2.  Self-declaration by the user.
        3.  Nursys verification, which can be initiated by employers for matched candidates.
-   **Authentication:** Standard email and password sign-up.
-   **Design:**
    -   Serene blue and green color scheme.
    -   Modern, simple, card-heavy UI.
    -   Professional font.

**User's preferred language**: English
